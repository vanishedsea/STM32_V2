# 模块与配套器件增补建议

## A. 建议优先补齐（关系到安全和稳定）

| 器件 | 建议数量 | 用途/理由 |
|---|---:|---|
| ST-Link V2 或兼容调试器 | 1 | SWD 下载、断点和故障定位 |
| 稳定的 5V/2A 电源 | 1 | 给 4×4 WS2812B 留足峰值余量 |
| 74AHCT125 或 SN74AHCT1G125 | 1 | 将 3.3V 数据可靠转换为 WS2812B 所需的 5V 逻辑；普通 74HC125 不等价 |
| 330–470 Ω 电阻 | 1 | WS2812B DIN 串联保护 |
| 1000 µF/10V 电解电容 | 1 | 灯板电源入口缓冲 |
| 100 nF 陶瓷电容 | 若干 | 各模块和电平转换器本地去耦 |
| 4.7 kΩ 电阻 | 2 | I2C 总线最终只保留一组上拉时使用 |
| 面包板、杜邦线、电源分配线 | 若干 | 原型搭建，电源线应比普通信号线更可靠 |
| CR2032 或匹配模块的电池 | 1 | DS3231 断电走时；先确认模块是否带充电电路 |

若三脚蜂鸣器板上没有驱动管，再补 S8050/2N2222、1 kΩ 电阻及保护二极管。若不确定，先发模块正反面清晰照片再接。

## B. 强烈建议的交互与调试模块

| 模块 | 推荐原因 |
|---|---|
| 2–3 个独立按键，或一个旋转编码器带按压 | 设置时间、切换页面、消音和进入菜单 |
| 3.3V USB-TTL（CH340/CP2102） | 输出日志；PA9/PA10 已预留 USART1 |
| 8 通道逻辑分析仪 | 检查 I2C、SPI 和 WS2812 时序，调试收益很高 |
| 无源蜂鸣器 | 如果希望播放不同音调或提示旋律，可替换/并行设计有源蜂鸣器 |

## C. 按功能选择的扩展模块

| 目标 | 可选模块 | 说明 |
|---|---|---|
| 联网/手机查看 | ESP8266、ESP-01S 或 ESP32-C3 串口模块 | 需要独立、足够电流的 3.3V 稳压，不能直接依赖弱小的板载 3.3V 输出 |
| CO₂ 监测 | SCD40/SCD41 | I2C，功能价值高，但价格和功耗高于普通温湿度模块 |
| 空气质量/VOC | SGP30/SGP40、BME680 | 会与现有温湿度/气压功能部分重叠，按需求选择 |
| 可插拔大容量日志 | MicroSD SPI 模块 | W25Q64 已能做短期环形日志；只有需要电脑直接取卡或更大容量时再加 |
| 掉电频繁写配置 | I2C/SPI FRAM | 写寿命高，但当前 W25Q64 配合磨损均衡通常已够用 |
| 功耗监测 | INA219/INA226 | 测量整机或灯板电压、电流和功耗 |
| 人体感应 | PIR 或毫米波存在传感器 | 实现靠近亮屏、无人自动降亮度 |

## D. 当前不建议盲目添加

- 更多温度传感器：SHT30、BMP280 和 DS3231 已经有三路温度信息；应先做校准和热源隔离。
- 第二块普通 I2C EEPROM：W25Q64 容量更大，除非有特殊写寿命需求。
- 大尺寸彩屏：STM32F103C8T6 的 SRAM 和 Flash 较紧，应先完成 OLED 版本。
- 直接用继电器模块控制市电：原型阶段先保持低压系统，市电需要隔离、保险和安全结构设计。

## E. 结构和测量注意事项

- SHT30 与 BMP280 应远离 STM32 稳压器、WS2812B 和电源模块，避免自热使温度偏高。
- BH1750 应面向环境光，避免被 WS2812B 直接照射；否则灯效会污染照度测量。
- BMP280 若用于气压/高度趋势，外壳需要通气孔，不能密封。
- OLED 与 WS2812B 的亮度都应支持软件限幅，降低电源噪声与发热。
