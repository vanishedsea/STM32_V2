# 硬件接线说明（当前版本）

## 1. STM32 引脚总表

| 功能 | STM32F103C8T6 引脚 | 外设端 | 说明 |
|---|---|---|---|
| I2C1 SCL | PB6 | 所有 I2C 模块的 SCL/SCK | 共享总线 |
| I2C1 SDA | PB7 | 所有 I2C 模块的 SDA/SDI | 共享总线 |
| DS3231 方波/闹钟 | PB1 | SQW | 可选，配置为外部中断输入 |
| SPI1 CS | PA4 | W25Q64 CS | 低电平有效 |
| SPI1 SCK | PA5 | W25Q64 CLK/SCK | SPI 时钟 |
| SPI1 MISO | PA6 | W25Q64 DO/MISO | Flash 到 MCU |
| SPI1 MOSI | PA7 | W25Q64 DI/MOSI | MCU 到 Flash |
| WS2812 数据 | PA8 | 电平转换器输入，再到 DIN | 预留 TIM1_CH1 + DMA |
| 蜂鸣器控制 | PB0 | SIG/IN/IO | 高低有效需实测模块 |
| 编码器 A 相 | PB12 | A | 内部上拉 |
| 编码器 B 相 | PB13 | B | 内部上拉 |
| 编码器按压 | 不连接 | C/SW/KEY | 不再使用编码器自带按压 |
| 独立确认按钮 | PB15 | 按钮另一端接 GND | 内部上拉，按下为低电平 |
| 串口调试 TX | PA9 | USB-TTL RX | 预留 USART1，可选 |
| 串口调试 RX | PA10 | USB-TTL TX | 预留 USART1，可选 |
| 板载状态 LED | PC13 | Blue Pill 板载 LED | 通常低电平点亮 |

PA11/PA12 暂留给 USB，PA13/PA14 保留给 SWD 下载调试，不分配给普通外设。

## 2. I2C 总线模块

下面五个模块并联到同一条 I2C1 总线：

- STM32 PB6 → 各模块 SCL（BMP280 某些板标为 SCK）
- STM32 PB7 → 各模块 SDA（BMP280 某些板标为 SDI）
- STM32 3.3V → 各模块 VCC/VIN
- STM32 GND → 各模块 GND

### DS3231（常见 6 脚：VCC、GND、SCL、SDA、SQW、32K）

| DS3231 | 连接 |
|---|---|
| VCC | 3.3V |
| GND | GND |
| SCL | PB6 |
| SDA | PB7 |
| SQW | PB1（可选） |
| 32K | 暂不连接 |

注意：如果是常见 ZS-042 板并装有 CR2032，不应让板上的充电电路给一次性 CR2032 充电。应确认板型并禁用充电支路，或者使用与该充电电路匹配的可充电电池。模块仅用 3.3V 供电时，也要核对其原理图和电池类型。

### SHT30（VCC、GND、SCL、SDA）

| SHT30 | 连接 |
|---|---|
| VCC | 3.3V |
| GND | GND |
| SCL | PB6 |
| SDA | PB7 |

### BMP280（常见 6 脚：VCC、GND、SCL/SCK、SDA/SDI、CSB/CS、SDO）

| BMP280 | 连接 |
|---|---|
| VCC | 3.3V |
| GND | GND |
| SCL/SCK | PB6 |
| SDA/SDI | PB7 |
| CSB/CS | 3.3V，选择 I2C 模式 |
| SDO | GND，地址选择为 0x76；也可接 3.3V 得到 0x77 |

### BH1750（VCC、GND、SCL、SDA、ADDR）

| BH1750 | 连接 |
|---|---|
| VCC | 3.3V |
| GND | GND |
| SCL | PB6 |
| SDA | PB7 |
| ADDR | GND，地址选择为 0x23；接高电平通常为 0x5C |

### 0.96 英寸 I2C OLED（常见为 SSD1306）

| OLED | 连接 |
|---|---|
| VCC | 3.3V |
| GND | GND |
| SCL | PB6 |
| SDA | PB7 |

### I2C 地址规划

| 模块 | 常用 7 位地址 |
|---|---|
| BH1750 | 0x23 |
| OLED | 0x3C（部分模块为 0x3D） |
| SHT30 | 0x44（部分配置为 0x45） |
| DS3231 | 0x68 |
| BMP280 | 0x76（SDO 接高时为 0x77） |

这些默认地址互不冲突。首次上电时软件仍需执行一次 I2C 扫描，以实际读到的地址为准。

多个模块通常都自带 SDA/SCL 上拉电阻。五块板并联后等效阻值可能过低，导致 MCU 灌电流过大或波形变差。建议最终只保留一组约 4.7 kΩ 上拉到 3.3V；原型阶段先测量 SDA/SCL 到 3.3V 的等效电阻，若明显低于约 2 kΩ，应拆除部分模块的上拉电阻。绝不能让任一 I2C 上拉到 5V。

## 3. W25Q64 SPI Flash（6 脚模块）

| W25Q64 丝印 | STM32 | 说明 |
|---|---|---|
| VCC | 3.3V | 禁止接 5V |
| GND | GND | 共地 |
| CS/SS | PA4 | 片选 |
| CLK/SCK | PA5 | SPI1_SCK |
| DO/MISO | PA6 | SPI1_MISO |
| DI/MOSI | PA7 | SPI1_MOSI |

如果模块实际引出了 8 个脚，还会出现 `/WP` 和 `/HOLD`；未使用时二者应上拉到 3.3V，不能悬空。模块旁建议放置 100 nF 去耦电容。

## 4. 4×4 WS2812B 矩阵（常见 4 脚：5V、GND、DIN、DOUT）

| 灯板 | 连接 |
|---|---|
| 5V/VCC | 独立稳定 5V 电源正极 |
| GND | 5V 电源负极，同时连接 STM32 GND |
| DIN | 74AHCT125 输出，经 330–470 Ω 串联电阻 |
| DOUT | 暂不连接，级联下一块灯板时使用 |

推荐数据链路：`PA8 → 74AHCT125 输入 → 74AHCT125 输出 → 330–470 Ω → DIN`。74AHCT125 用 5V 供电，`/OE` 接 GND，并在芯片电源脚旁放 100 nF 去耦电容。

16 颗灯在全白满亮时理论电流约 16 × 60 mA = 0.96 A。建议使用 5V/2A 电源，在灯板 5V 与 GND 入口并联 1000 µF（耐压至少 6.3V，建议 10V）电解电容。不要用 Blue Pill 的 3.3V 引脚或 ST-Link 供电引脚给灯板供电。

如果 STM32 用 USB 供电、灯板用外部 5V，只连接两侧 GND 和数据链路，不要再把两路 5V 直接相连，以免回灌。上电顺序尽量保证先共地，再送数据。

## 5. 三脚有源蜂鸣器模块

| 蜂鸣器 | 连接 |
|---|---|
| VCC | 优先 3.3V（先确认模块允许的工作电压） |
| GND | GND |
| SIG/IN/IO | PB0 |

有源蜂鸣器只能控制响/停，不能像无源蜂鸣器那样稳定播放不同音调。不同模块可能高电平触发或低电平触发，首次测试时用短脉冲确认，并在软件配置中保留“有效电平”选项。

如果这不是带驱动三极管的模块，而只是蜂鸣器本体，不要直接由 GPIO 驱动；应增加 S8050/2N2222 等 NPN 三极管、约 1 kΩ 基极电阻，并视蜂鸣器类型增加反向保护二极管。

## 6. EC11 与独立确认按钮

EC11 现在仅负责旋转：`VCC=3.3V`、`GND=GND`、`A=PB12`、`B=PB13`。原来的 `C/SW/KEY` 不再接入 STM32，PB14 也不再使用。

增加一个常开瞬时按钮：一端接 PB15，另一端接 GND。PB15 已启用内部上拉，不需要外接电阻。若使用四脚轻触按键，同一侧两脚通常内部相连，应使用分属两侧的两个脚；建议断电后用万用表通断档确认。

独立按钮短按用于进入菜单和确认选项，长按约 800 ms 用于返回首页或退出菜单。详细操作见 `03_界面与操作.md`。

## 7. 下载与调试

ST-Link 连接：

| ST-Link | STM32 |
|---|---|
| SWDIO | PA13 |
| SWCLK | PA14 |
| GND | GND |
| 3.3V/Vref | 3.3V（主要作目标电压参考） |

建议由目标板自己的稳定电源供电，ST-Link 与目标板共地。不要在不清楚 ST-Link 克隆板供电方式时，同时由多路电源向 3.3V 轨供电。

## 8. 首次通电顺序

1. 暂时不接 WS2812B 和蜂鸣器，只接 STM32、ST-Link 与一块 I2C 模块。
2. 检查 3.3V 与 GND 是否短路，确认所有模块丝印方向。
3. 运行 I2C 扫描，逐块增加模块并确认地址。
4. 连接 W25Q64，读取 JEDEC ID；常见 W25Q64 的 ID 应匹配其器件型号，但以模块实际芯片为准。
5. 单独验证蜂鸣器的有效电平。
6. 最后连接外部 5V、共地、电平转换器和 WS2812B，先用低亮度点亮单颗灯。
