# STM32F103 项目驱动的 C、C++ 与嵌入式系统教材

> 适用项目：`STM32F103_MultiSensor_System`  
> 硬件：STM32F103C8T6、DS3231、SHT30、BMP280、BH1750、SSD1306 OLED、W25Q64、EC11、独立按钮和有源蜂鸣器  
> 工具：VS Code + Keil5/ARMCC5 + ST-Link  
> 教材版本：2026-07-17

这套教材以你桌面上的真实工程为实验平台，但学习目标不局限于“会修改这个工程”。完整目标是建立一条可以迁移到其他嵌入式项目的知识链：

```text
C 语言 → 指针与内存 → 数据结构 → STM32/Cortex-M3
       → 裸机架构与 FreeRTOS → C++ 与面向对象
       → 嵌入式 C++ → 编译、链接、ABI 与运行时
```

## 如何使用这套教材

1. 从 `00_学习方法与路线.md` 开始，不要跳过其中的实验规则。
2. 第 1～7 章建立 C 与数据结构基础，第 8～12 章进入 STM32、驱动、裸机和 FreeRTOS，第 13～15 章学习 C++，第 16 章开始研究编译链接与 ABI。
3. 每读完一章，先完成“检查点”，再做练习。答案不是为了背诵，而是为了确认你能解释现象。
4. PC 示例放在 `Examples/`。STM32 实验使用现有两套工程，但每次只改一个变量，并记录修改前后的现象。
5. 稳定工程出现异常时，先恢复本章实验改动，再排查硬件。不要一次叠加多项未知修改。

## 两套工程在教材中的角色

### 裸机工程

路径：`../01_BareMetal_Keil/`

它用于学习：

- C 语言模块化；
- 函数指针；
- 固定数组和环形队列；
- 协作式调度；
- 中断与主循环的通信；
- 非阻塞状态机；
- `WFI` 与空闲等待；
- 可预测的静态内存。

### FreeRTOS 工程

路径：`../02_FreeRTOS_Keil/`

它用于学习：

- 抢占式调度；
- 静态任务和任务栈；
- Queue 与 Mutex；
- 优先级和并发；
- 阻塞等待；
- 栈溢出检查；
- 裸机系统与 RTOS 的结构对照。

## 学完以后应具备的能力

你应该能独立回答并验证下面的问题：

- 为什么 `uint32_t` 在 STM32 上通常是 4 字节？
- 数组名、数组首元素地址和指针变量有什么区别？
- 为什么中断共享变量常见 `volatile`，但 `volatile` 不能代替原子性？
- 为什么事件队列使用环形数组而不是链表？
- 为什么 W25Q64 编程前需要写使能，覆盖时需要扇区擦除？
- 为什么 OLED 全屏缓冲区正好是 1024 字节？
- 裸机任务和 FreeRTOS 任务在调度本质上有什么区别？
- C 的函数指针接口与 C++ 虚函数有什么联系？
- 构造函数、虚函数、模板分别可能带来哪些 Flash/RAM 成本？
- ARMCC 输出中的 Code、RO、RW、ZI 分别代表什么？
- MCU 复位之后，谁初始化 `.data` 和 `.bss`，谁调用 `main()`？

这些问题不是目录装饰，而是整套教材的验收目标。
