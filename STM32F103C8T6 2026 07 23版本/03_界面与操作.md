# 界面、EC11 与按钮操作

两个系统版本都只维护一份界面源码，并内置两种主题：

- `Classic`：仪表盘、气候、气压照度和系统状态页面。
- `Nokia`：2×2 宫格目录，选中框反色显示并使用 6 帧缓动过渡。

## 接线

EC11 只负责旋转，确认操作使用独立按钮：

| 器件端 | STM32F103C8T6 | 说明 |
|---|---|---|
| EC11 VCC | 3.3V | 当前编码器模块供电 |
| EC11 GND | GND | 共地 |
| EC11 A | PB12 | 旋转 A 相 |
| EC11 B | PB13 | 旋转 B 相 |
| EC11 C/SW/KEY | 不连接 | 不使用编码器自带按压 |
| 独立按钮一端 | PB15 | 内部上拉 |
| 独立按钮另一端 | GND | 按下为低电平 |

四脚轻触按钮应使用分属两侧的两个脚，同一侧两个脚通常内部已经相连。

## 操作逻辑

- 数据页旋转：依次切换 DASH、CLIMATE、AIR LIGHT 和 SYSTEM 页面。
- 数据页短按：打开菜单。
- 菜单旋转：移动当前选中项。
- 菜单短按：进入页面或执行当前选项。
- 菜单长按约 800 ms：退出菜单，返回原数据页。
- 数据页长按约 800 ms：返回 DASH 首页。

菜单第二组包含 `STYLE`、`BEEP`、`EXIT` 和 `ABOUT`。在 `STYLE` 中短按可切换 Classic/Nokia；`BEEP` 控制开机和存储故障提示音。

## Keil Target

| 工程 | Target | 首次启动默认主题 |
|---|---|---|
| 裸机 | `BareMetal` | Classic |
| 裸机 | `BareMetal-Nokia` | Nokia |
| FreeRTOS | `FreeRTOS` | Classic |
| FreeRTOS | `FreeRTOS-Nokia` | Nokia |

Target 只决定首次默认值。主题和蜂鸣器设置保存在 W25Q64 的配置区域，传感器日志从 `0x010000` 开始，两者不会重叠。裸机优化版本使用 16 字节设置日志，正常情况下累计 256 次设置修改后才需要擦除一次 4 KiB 配置扇区。

## 软件参数

两个版本的参数都位于 `App/Inc/app_config.h`：

```c
#define APP_ENCODER_SCAN_PERIOD_MS      2U
#define APP_ENCODER_BUTTON_DEBOUNCE_MS  20U
#define APP_ENCODER_LONG_PRESS_MS       800U
#define APP_ENCODER_REVERSE             0
```

如果旋转方向相反，将 `APP_ENCODER_REVERSE` 改为 `1`，或者交换 A、B 两根线。裸机版通过 PB12/PB13 双边沿 EXTI 捕获旋转，2 ms 任务消费累计步进；FreeRTOS 版由最高优先级 2 ms 任务扫描。PB15 在两个版本中都使用 20 ms 稳态消抖。

I2C 当前为 400 kHz。如杜邦线过长导致花屏或设备偶发掉线，可将 `APP_I2C_CLOCK_HZ` 降为 `100000U`，代价是动画刷新速度降低。
